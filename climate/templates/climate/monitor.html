Storage and optimisation

  • Data lake: {{ datasets }} datasets, {{ lake_kb }} KB, split into decade partitions; a request opens only the partitions that overlap its year range.
  • Datasets are cached in memory after the first read, and the live feed is cached for 5 minutes, so many viewers cost one upstream call.
