About the project

EarthScape Climate Agency

A climate change analysis and monitoring system built as an Aptech eProject. It collects climate data, stores it in Hadoop HDFS and MongoDB, processes it with MapReduce, analyses it with machine learning, and shows it in interactive dashboards with alerts, reports, support and an AI assistant.

What it does

  • Role-based access: Administrators and Climate Analysts.
  • Data ingestion: CSV/JSON uploads, GeoTIFF satellite imagery, a real-time sensor API and live weather/CO₂ feeds.
  • Big data: Hadoop HDFS storage and MapReduce jobs (Hadoop Streaming), plus a MongoDB document store.
  • Machine learning: trend prediction to 2035, anomaly detection and correlation analysis.
  • Dashboards, alerts and reports: interactive charts and maps, threshold alerts, PDF/CSV reports and a Tableau extract.
  • Support: a ticketing system and an AI chatbot that answers climate and site questions.
