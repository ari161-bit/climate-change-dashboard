# Demo video script (about 6 minutes)

The brief asks for a video showing the complete working application. Record this walkthrough with any screen recorder (Windows: Win+G, or OBS). It follows the manual test checklist, so each scene is also a verification.

| Time | Scene | Say / show |
|---|---|---|
| 0:00 | Sign-in page | "EarthScape Climate Agency portal, built on Django with a partitioned data lake." Point out the demo accounts. Try a wrong password, then sign in as the analyst |
| 0:30 | Dashboard top | Warming stripes (hover a year), headline cards, alert cards. Press **Since 1980** and show everything update |
| 1:15 | The warming signal | Temperature chart with anomaly diamonds, Keeling curve, 2050 projection and the *Model selection* panel |
| 2:00 | Drivers and impacts | Emissions by country, cumulative emissions, sea level, glaciers, disasters |
| 2:40 | Regions, cities, correlation | Latitude bands (Arctic amplification), city ranking, correlation heat map and the caveat |
| 3:10 | Data explorer | Pick a dataset, switch country/city and column; show the catalogue with source, checksum, missing %. Note analysts have no download button |
| 3:50 | Live and Satellite | Live cards and alerts; switch Satellite to the aerosol layer for a polluted city |
| 4:20 | Support | Send a message as the analyst. Toggle dark theme |
| 4:40 | Administrator | Sign out, sign in as admin. Lower a threshold and show the alert change. Reply to the message. Upload a CSV |
| 5:20 | Models and monitor | Retrain all models, show the history row. Open the Performance monitor |
| 5:50 | Wrap-up | Download a backup, mention the architecture diagram and the 31 automated tests |
